# Fork perso — UI sobre Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer les portraits pixel par un monogramme, supprimer le bureau animé et les fonctions vocales, mettre la liste d'agents en colonne à gauche, réduire le bruit d'inbox dans le terminal de god, et habiller l'app façon Orca (sombre par défaut).

**Architecture:** Changements limités au renderer React (`src/renderer/src`), plus le prompt injecté et le nudge d'inbox (`src/main/hive.ts`, `src/shared/hiveNudge.ts`). On garde les noms de tokens `--cth-*` et de composants `Pixel*` (seules les valeurs/l'intérieur changent) pour limiter la divergence avec l'upstream ; le code mort (scène Pixi, realtime, Free Flow) est supprimé franchement.

**Tech Stack:** Electron + electron-vite, React 18, TypeScript, zustand, xterm.js, tests `node --test` en `.cjs` avec `test/load-ts.cjs` pour charger du TS.

**Spec:** `docs/superpowers/specs/2026-11-05-ui-perso-design.md`

## Global Constraints

- `npm run typecheck` et `npm run test:focused` passent à la fin de chaque tâche.
- `Agent.character` (`OfficeCharacterName`) reste dans le store et la persistance ; `OFFICE_CAST`, `DEFAULT_CHARACTER`, `OfficeCharacterName` restent exportés.
- Aucun chargement de police réseau : polices embarquées dans `src/renderer/src/assets/fonts/` + `design/fonts.css` (cf. `test/bundled-fonts.test.cjs`).
- Textes UI via i18n (`src/renderer/src/i18n/locales/{en,ar,zh-CN}.json`) ; clés supprimées retirées des trois fichiers.
- Couleurs uniquement via tokens `--cth-*` (pas de hex en dur dans les composants, sauf `AgentMonogram` qui lit des tokens).
- Palette Orca (sombre / clair) : fond `#0a0a0a`/`#ffffff`, latéral+cartes `#171717`/`#fafafa`, atténué `#262626`/`#f5f5f5`, texte `#fafafa`/`#0a0a0a`, secondaire `#a1a1a1`/`#737373`, bordures `#ffffff12`/`#e5e5e5`, input `#ffffff26`/`#e5e5e5`, focus `#737373`/`#a1a1a1`.
- Statuts : working `#edb200`, attente humain `#f05100`, idle `#525252` (sombre), blocked/erreur `#fb2c36`, success `#00c758`.
- Accents (sombre) : sky `#00bcfe`, mint `#00d294`, lemon `#fcbb00`, coral `#ff667f`, lilac `#a685ff`, peach `#ff8b1a`.
- Agents Claude uniquement : pas de branche par provider pour le nudge.
- Ne pas réintroduire la livraison d'inbox via hook `Stop` (`src/main/hooks.ts`).

## Review Focus

1. Équipe sauvegardée avec des `character` variés (et un `officeTheme`/`tvShowOffices` persistés dans la config) → restauration sans erreur ni crash au démarrage. Test : Task 2.
2. Nom d'agent vide, emoji, accentué (« Élodie »), ou très long → monogramme lisible, jamais vide. Test : Task 1.
3. Nudge en attente dans la queue persistée **avec l'ancien texte long** (reload après mise à jour) → toujours reconnu par `isInboxNudge` (règle « un seul nudge en attente »). Test : Task 5.
4. Beaucoup d'agents (15+) → la colonne défile verticalement, « Ajouter un agent » reste accessible, le popover de note ne sort pas de l'écran. Vérif manuelle Task 3.
5. Utilisateur ayant explicitement choisi le thème clair (`localStorage cth.theme = 'light'`) → reste en clair ; seul le défaut sans préférence passe en sombre. Test : Task 7.
